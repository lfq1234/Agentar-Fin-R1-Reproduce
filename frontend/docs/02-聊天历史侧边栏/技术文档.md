## 1. 总览

本期在 `01-前端` 已落地的单会话聊天界面上，新增**左侧历史侧边栏**与**左上角个人文档入口**。

技术决策：

- **不新增后端接口**：复用现有 `/api/v1/chat`、`/api/v1/analyze`、`/api/health`。
- **不新增依赖**：状态仍用 `useState` + 自定义 Hook，样式仍用原生 CSS。
- **前端本地会话管理**：`useChat` 从维护单条 `history` 升级为维护 `ChatSession[]` 集合，刷新后数据丢失（后续可接后端会话列表接口）。
- **最小侵入**：现有 `MessageList`、`ChatInput`、`AnalyzePanel`、`Header` 等组件接口基本不变，仅 `App.tsx` 布局与 `useChat` 内部状态模型变化。

## 6. `useChat` 改造（`src/hooks/useChat.ts`）

核心变化：从单会话状态升级为会话集合。

```ts
// 初始创建一个空白会话
const createBlankSession = (): ChatSession => ({
  id: crypto.randomUUID(),
  title: "新对话",
  history: [],
  conversationId: null,
  scene: "Banking",
  createdAt: Date.now(),
  updatedAt: Date.now(),
});

export function useChat() {
  const [sessions, setSessions] = useState<ChatSession[]>(() => [createBlankSession()]);
  const [currentSessionId, setCurrentSessionId] = useState<string>(sessions[0].id);
  const [personalDocsOpen, setPersonalDocsOpen] = useState(false);

  const currentSession = sessions.find((s) => s.id === currentSessionId) ?? sessions[0];

  // send / runAnalyze 内部改为更新 currentSession 的 history 与 conversationId
  // createSession / deleteSession 维护 sessions 数组与 currentSessionId
}
```

关键规则：

- `send` 仅在当前会话内追加消息，并更新当前会话的 `conversationId`、`updatedAt`。
- `runAnalyze` 不受会话切换影响，仍分析最近一条助手回复。
- `createSession` 追加空白会话并激活；`deleteSession` 删除后若当前会话被删，则切换到 `updatedAt` 最新的会话，若无会话则自动新建。
- 会话标题自动计算：

```ts
function deriveTitle(history: UiMessage[]): string {
  const firstUser = history.find((m) => m.role === "user");
  if (!firstUser) return "新对话";
  const text = firstUser.content.trim();
  return text.length > 20 ? text.slice(0, 20) + "…" : text;
}
```

## 7. `App.tsx` 布局改造

由垂直布局改为水平两栏：

```tsx
<div className="app-shell">
  <Sidebar
    sessions={sessions}
    currentSessionId={currentSessionId}
    personalDocsOpen={personalDocsOpen}
    onSelectSession={setCurrentSessionId}
    onCreateSession={createSession}
    onDeleteSession={deleteSession}
    onTogglePersonalDocs={() => setPersonalDocsOpen((v) => !v)}
  />

  <div className="app-main">
    {personalDocsOpen ? (
      <PersonalDocsPanel onClose={() => setPersonalDocsOpen(false)} />
    ) : (
      <>
        <Header ... />
        <ErrorBanner ... />
        <section className="chat-area">...</section>
        <AnalyzePanel ... />
      </>
    )}
  </div>
</div>
```

> 注意：当切换会话时，应同时 `setPersonalDocsOpen(false)`，确保回到聊天视图。
