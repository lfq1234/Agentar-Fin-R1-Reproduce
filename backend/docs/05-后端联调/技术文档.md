## 1. 总览

本模块是 `Agentar-Fin-R1-Reproduce` 的**后端联调层**，**不开发前端**。职责是把已落地的三层在后端进程内串起来做端到端集成验证：

- **模型层（01）**：`app/model/` —— `get_model()` 文本生成 + `get_embedder()` 嵌入（api/local 双模式）。
- **Agent 层（02/04）**：`app/agent/system.py` 的 `run()` —— 路由→RAG→专家→审核→风控→结构化。
- **后端层（03）**：`app/routes/chat.py` + `app/services/*` + SQLite 落库。

```
┌─────────────────────────────────────────────────────────────┐
│  联调客户端（不涉及前端）                                      │
│  FastAPI TestClient / curl / requests 脚本                   │
└───────────────────────────┬─────────────────────────────────┘
                            │  GET /api/health
                            │  POST /api/v1/chat   {message, scene?, user_id?, conversation_id?}
                            │  POST /api/v1/analyze {message, scene?}
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  backend (03)  FastAPI :8000                                  │
│  routes/chat.py → services/chat_service.py / analyze_service.py│
│       │ await agent_run(message, scene, structured)           │
│       ▼                                                       │
│  app/agent/system.py  run()  （02 编排 + 04 内容）            │
│       ├─ 路由 → RAG(04 retrieval.py, 用 01 get_embedder)      │
│       ├─ 专家(5) / 审核 / 风控 / 信息查询                      │
│       └─ 结构化                                               │
│       │ 文本生成调用 01 get_model()                            │
│       ▼                                                       │
│  SQLite (aiosqlite, ./agentar.db)  conversations / messages   │
└─────────────────────────────────────────────────────────────┘
```

**关键事实（已核对后端代码）**
- 03 的 `app/services/chat_service.py` 第 51 行 `result = await agent_run(message=req.message, scene=req.scene, structured=False)`；`analyze_service.py` 第 9 行 `result = await agent_run(message=req.message, scene=req.scene, structured=True)`。**链路已接通，05 联调重点是端到端验证而非接线。**
- 路由（`app/routes/chat.py`）暴露 `GET /api/health`、`POST /api/v1/chat`、`POST /api/v1/analyze`（**统一 `/api` 前缀**），由 `app/main.py` 的 `include_router(prefix="/api")` 挂载。
- 后端使用 SQLite：`config.db.type=sqlite`（默认），异步驱动 `aiosqlite`，库文件默认 `./agentar.db`；`lifespan` 调 `init_db()` 建表。
- 01 已扩展 `get_embedder()`（api/local），04 的 `retrieval.py` 已实现 ingest/parse/embed/store/search（embed 经 01）。

## 3. 联调环境 / 配置

- **后端启动**：`cd backend && uvicorn app.main:app --reload --port 8000`。
- **模型（01）**：
  - api 模式：`config.yaml` 的 `model.api`（OpenAI 兼容，需 `OPENAI_API_KEY` 环境变量）；`emb.api` 同理。
  - local 模式：`model.local` / `emb.local` 指向本机 vLLM `/v1`（如已起）。
- **数据库（03）**：`config.yaml` 设 `db.enabled: true`、`db.type: sqlite`（库文件默认 `./agentar.db`）。
- **依赖**：后端 venv 已含 `fastapi` / `sqlmodel` / `aiosqlite` / `agentscope` / `openai` 等；联调新增测试仅需 `httpx`（TestClient 依赖，FastAPI 测试标配，通常已随 fastapi 安装）。

## 4. 联调手段（不涉及前端）

| 手段 | 用途 | 说明 |
| --- | --- | --- |
| FastAPI `TestClient` | 集成测试主力 | `from fastapi.testclient import TestClient; client = TestClient(app)`；直接打 `/api/v1/chat` 等，走完整 ASGI 栈（含 lifespan/init_db）。 |
| `curl` | 手动冒烟 | 起 `uvicorn` 后 `curl -X POST localhost:8000/api/v1/chat -d '{...}'`。 |
| `requests` 脚本 | 批量/组合联调 | 多轮对话、续聊一致性、RAG 命中断言。 |
| stub 开关（可选） | 无模型时验证后端+落库 | `AGENT_STUB=1` 时 `run()` 返回固定 `AgentResult`（仅测试，不进生产）。 |

> 以上均运行在后端进程/Python 环境内，**不涉及任何浏览器或 UI 框架**。

### 5.3 集成测试（TestClient，推荐）
新增 `tests/test_integration_chat.py`：
```python
import pytest
from fastapi.testclient import TestClient
from app.main import app

@pytest.fixture
def client():
    with TestClient(app) as c:   # 触发 lifespan → init_db
        yield c

def test_health(client):
    assert client.get("/api/health").json() == {"status": "ok"}

def test_chat_returns_reply(client):
    r = client.post("/api/v1/chat", json={"message": "存款保险限额是多少？", "scene": "Banking", "user_id": 1})
    assert r.status_code == 200
    body = r.json()
    assert body["reply"]
    assert isinstance(body["compliance_notes"], list)
    assert isinstance(body["risk_flags"], list)
    assert body["conversation_id"] is not None

def test_analyze_structured(client):
    r = client.post("/api/v1/analyze", json={"message": "推荐一只稳健基金", "scene": "MutualFunds"})
    assert r.status_code == 200
    b = r.json()
    assert isinstance(b["slots"], dict)
    assert isinstance(b["tool_plan"], list)
```
- 运行：`pytest tests/test_integration_chat.py -q`。

### 5.4 RAG 命中验证（04）
```python
def test_rag_hit(client, tmp_path):
    from app.agent.retrieval import Retriever
    ret = Retriever(db_path=str(tmp_path / "kb.db"))
    ret.ingest_text("存款保险条例：单一存款人最高偿付限额为人民币50万元。", domain="Banking")
    hits = ret.search("存款保险限额", domain="Banking", top_k=3)
    assert hits and "50万元" in hits[0].text
```
- 接 `/api/v1/chat` 验证 `reply` 引用了该条款（断言命中检索片段）。

### 5.5 续聊一致性验证（03）
```python
def test_continuation(client):
    r1 = client.post("/api/v1/chat", json={"message": "你好", "scene": "Banking", "user_id": 2})
    cid = r1.json()["conversation_id"]
    r2 = client.post("/api/v1/chat", json={"message": "继续", "scene": "Banking", "user_id": 2, "conversation_id": cid})
    assert r2.json()["conversation_id"] == cid
```

### 5.6 模型不可用降级验证（01）
- 临时置错误 `model.api.base_url` 或清空 `OPENAI_API_KEY`。
- 断言：`/api/v1/chat` 不 500 无信息；返回可识别错误（`ModelInvokeError` 已被 `run()` 捕获，reply 含降级提示或返回 4xx/5xx 带清晰 message）。
